# GetDP documentation dataset

This directory contains concise Markdown summaries of selected topics from the GetDP Reference Manual 4.0.0 (November 16, 2026).

Files:
- `overview.md` — solver purpose, capabilities and main concepts.
- `installation.md` — obtaining binaries and building from source.
- `data_formats.md` — `.pro`, `.msh`, `.pre`, `.res` and exported results.
- `command_line.md` — execution stages and command-line options.
- `problem_definition.md` — the main objects used to define a model.
- `tutorials_and_examples.md` — tutorial catalogue and example workflows.
- `troubleshooting.md` — selected FAQ topics.
- `source_and_attribution.md` — provenance, version and attribution.

These are original summaries, not the official manual. See `source_and_attribution.md` and the official source at https://getdp.info/doc/texinfo/getdp.txt.
