## Nature of these documents

These Markdown files reorganize and summarize selected information from the reference manual for use as a small Retrieval-Augmented Generation demonstration dataset.

They are not the official GetDP documentation, are not a complete reproduction of the reference manual, and may omit details or advanced syntax. For authoritative and complete information, consult the original manual and the official project resources.

The summaries intentionally avoid reproducing long passages of the manual verbatim. GetDP names, object names, command-line options and file extensions are retained where needed for technical accuracy.

## Version sensitivity

The source manual is version 4.0.0, dated November 16, 2026. GetDP's command-line options, supported formats, build options and capabilities may differ in other versions or in binaries built with different optional dependencies.

When answering version-specific questions, check the installed GetDP version and consult documentation matching that version.
